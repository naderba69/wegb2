# الأرشيف — محرّما التشغيل
هذان مولِّدا التوسعة اللذان صُنعا في عهد رقعة ① ثم استُهلا: كلَّداهما مهمةً
واحدة أنجزاها، وأثبت التاريخ أن تشغيلهما مرةً ثانية يولّد تزويجاً وتلوّثاً
(حادتا v549–v1037 وCJK موثقتان في الجرد). من هنا:
- لا npm script يشير إليهما، ولا سطرٌ في scripts/ خارج هذا الدليل يستوردهما — بوابة K28 تحرّس ذلك.
- القراءة للنستالجيا مسموحة، والتنفيذ ممنوع بأمر المالك لا بتقديري.
- التوسعة القادمة (رقعة ②) تُولَّد يدياً داخل الدور، لبنةً لبنة، كما وُلدت الأخيرة.
