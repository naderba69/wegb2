## 1) الميثاق

### صفر — التسلسل المطلق (Serielle Führung)
- المنتج كلّه **طابور واحد**: اليوم ①→…→⑥ «أغلقتُ يومي» → كبسولة المساء → الغد.
- **لا زر تخطٍّ ولا رابط قفز**: كل مقفل يظهر **مع سببه وشرط فتحه**.
- شاشة = نيّة واحدة؛ ≤ نصف شاشة في خطوات الدرس؛ زر واحد «التالي».

### القرارات المحسوسة (8 + 4 سلوك)
| # | القرار |
|---|---|
| 1 | الدرس = **معالج 5 خطوات**: خمّن ← قاعدة ← أمثلة ← تطبيق (≤3 تمارين) ← خلاصة |
| 2 | الرئيسية «اليوم» = بوابة الاسترجاع ← Stepper ← **مراجعة الأخطاء المتكرّقة** ← إغلاق يدوي ← كبسولة المساء |
| 3 | **5 تبويبات**: اليوم · الدرس · تدرّب · اختبر · تقدّمي |
| 4 | تمارين الزائد (>3) ← «تدريب إضافي» ترتحل إلى «تدرّب» |
| 5 | **إعادة بناء كاملة** + تجديد بصري — الأساس **B** (`images/dirB-today.png`): داكن أزرق-أسود + بطاقات أردوازية + أخضر حيّ `#22c55e` + زوايا دائرية — اتفق عليه المالك 2026-10-02 بعد نقض A |
| 6 | الصفحة القديمة → **`/alt` حجر** حتى P5 ثم حذف |
| 7 | التنفيذ: **هيكل فارغ + تبويبات + شاشة اليوم (P1)** ثم المعالج (P2) |
| 8 | «تدرّب» يفتح **بعد إغلاق اليوم فقط** · «تقدّمي» مشاهدة سلبية بلا روابط محتوى |
| 9 | سلوك: فتح مباشر للمهمّة الجارية · يوم نسيته ← استرجاع يومين + تعويض · إغلاق يدوي |
| 10 | **داكن افتراضياً · جوّال أولاً · عربي واجهة 100% · ألماني محتوى نقي بترجمة تحته** |

### منهج العمل (ثابت)
- لكل دفعة: **بوابة جديدة تسقط أولاً ثم تنجح** → `tsc` → `smoke` → `interaktiv` → `build` → قراءة عدائية → صفّ في `docs/qualitaet.md` → Commit.
- **لا يُحذف بوابة قديمة — تُعاد صياغتها** بصدق عند نقل المكوّن (مثال: محتوى `/alt` يُفحص بمساره الجديد لا يُلغى).
- خطأ متكرّر: إصلاح حالة ← مسح أخواته ← بوّابة ← قاعدة فحص مسبق (ثلاث ضربات).
