## ③ ما **لم** يُنجز — ولا سيُنجز بأداة (حدود معلنة عن قصد)
1. **حكم إنساني لامتحان Speaking الحقيقي** — التطبيق يدرّب (12 بطاقة مختبر + منصة عرض) ويحاكي ويقدّر ذاتياً بمرآة خمسة أركان، لكنه لا يدّعي مكانة ملاحظ القاعة. لا بوابة ستُكتب له: لأنه مستحيل.
2. **استماع «حيّ» (راديو/بودكاست)** — محظور بقرار مالك ثابت: «لا روابط». البديل المُنفَّذ: HörLabor على بنك النصوص. من يريد إذاعة حقيقية يفتح نافذة أخرى — خارج العقد.
3. **جودة النطق بيد الجهاز** — TTS يتبدد في بيئة اختبار، ويعتمد أصوات المتصفح الألماني؛ وُضع «🔇» صادقاً بدل الصمت ووضعُ الامتحان مؤجَّل عمداً عند غياب الصوت (قرار أمانة لا كسل).

## ④ ما هو «في طور الإنجاز» — الصدق كامل
**صفر مرحلة جارية**. الخطة الثمانية منتهية عن آخرها، وسطر «🔜 تالية» لا وجود له في الوثيقة. الموجود فعلاً ثلاثة أنواع:
- **قائمة توسيع معلَّقة تنتظر أمراً** (ليست متأخرة عن خطة — لا خطة لها): رقعة ② للمفردات (~8 ألواح ≈ +1,500 بطاقة → نصف الطريق إلى التراكمي 4000) · توسيع texts.json 36→72 (يغذي القراءة والاستماع معاً) · جولة jsdom للمراكز الـ15 الباقية · أرشفة مولّديّ المفردات بعد استهلاكهما.
- **حالة تشغيل لا حالة مشروع**: الإنتاج منطفئ الآن لأن البيئة باردة (node_modules/.next تتبخر بين الأدوار — سياسة الرمال، لا عيب بناء). البوابات شُغِّلت الليلة كلها خضراء؛ إحياء الإنتاج: `npm install && npm run build && npx next start -p 3000 -H 0.0.0.0` (أمر إقلاع، لا أمر كود).
- **قيدان تقنيان مسجلان بلا ضرر**: لا git في مساحة العمل (فقدنا تاريخ نسخ — يعوّضه أن كل مولّد idempotent/مقفل ذاتياً) · ids المفردات فيها فجوات من تطهير الازدواج (v549–v1037 لـ1022 بطاقة — عرَض تجميلي، لا يُكسر شيئاً لأن كل المحركات تَعُدّ لا ترقّم).
