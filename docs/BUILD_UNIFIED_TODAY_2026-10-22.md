## 2) الخريطة البصرية — 5 خطوات موحّدة لكل يوم

كل يوم مهما كان نوعه (lerntag / festigung / wochencheck / Abschluss) يُعاد تجميعه بصرياً إلى 5 محطات ثابتة:

```
┌─ اليوم الموحّد — خط واحد من الأعلى إلى الأسفل ─────────────────┐
│ Header: تاريخ + اليوم N/378 + شارة الوحدة (M1/M2…)             │
│ GoalBar: 90 دقيقة + progress شريط                              │
├─ ① التهيئة والاسترجاع  ─────────────────  wiederholen/kapsel   │
│    │  الاسترجاع التراكمي + كبسولة 1/7/30 + تحقق استقلال مستحق │
│    │  (في اليوم 1: ترحيب فقط)                                   │
├─ ② الدرس — اكتشف وافهم ───────────────  grammatik (LektionWizard)│
│    │  6 طبقات الاستوديو (الهوية→المشهد→الاكتشاف→البصري→…)     │
│    │  — يظهر فقط إذا كان اليوم يحمل topicId (Mon/Mi أو A0 يومياً)│
│    │  — إن لم يوجد درس: تُعرض بطاقة «اليوم بلا قاعدة جديدة»   │
├─ ③ الاستيعاب — اسمع واقرأ ───────────  wortschatz/lesen/hoeren │
│    │  مفردات جديدة + نص موجّه + حوار مسموع + شريط Schatten     │
│    │  — مستويات A1/A2/B1/B2 بأشكال مختلفة (انظر §3)           │
├─ ④ الإنتاج — اكتب وتحدّث ───────────  schreiben/sprechen/partner│
│    │  كتابة قصيرة/مشروع + تحدث حر + محادثة شريك + Teil 2/3    │
│    │  — B1/B2: إنتاج أكثر، A0/A1: إنتاج موجه                  │
├─ ⑤ التثبيت والفحص ──────────────────  check + fehler + balance│
│    │  Tagescheck/Prüfung + دفتر أخطاء + خريطة أسبوع + إغلاق اليوم│
│    │  — بوابة الوحدة (ModulTor) تظهر هنا إن كانت مقفلة        │
└────────────────────────────────────────────────────────────────┘
        الخط العمودي + نقاط 5 + قفل/صح على كل نقطة
```

### التجميع التقني

```ts
type StepId = 1|2|3|4|5;
function stepOf(task: DayTask, dayType: DayType): StepId {
  if (task.kind === "wiederholen" || task.verifyFor) return 1;
  if (task.kind === "grammatik") return 2;
  if (["wortschatz","lesen","hoeren","aussprache"].includes(task.kind)) return 3;
  if (["schreiben","sprechen","partner","briefe","schulsim"].includes(task.kind)) return 4;
  return 5; // check + wiederholen(closing) + fehler + injected tools
}
```

- **Gating:** Step N+1 مقفل حتى `allTasksInStep(N).every(passed || submitted)` — نفس عتبة 80% الحالية لكن على مستوى الخطوة لا المهمة المفردة.
- **الرؤية:** كل الخطوات مرئية دائماً (عنوان + أيقونة + عدد المهام)، المحتوى مطوي حتى الفتح.
- **التوافق مع buildDay:** لا تغيير في `lib/plan.ts` — فقط تجميع بصري. الخطة الحتمية 378 يوم تبقى byte-identical (K260c).

### الخطوة ② — الدرس (قلب التحول)

> هذه الخطوة هي الاستوديو التحريري 2.0 — كل الأفكار الـ49 تتجمع هنا.

#### أ) الطبقات الثماني الجديدة (توسيع 6 → 8)

```
1. الهوية — شارة مستوى + هدف + متطلب (موجود)
2. المشهد الافتتاحي — حوار/نص مصغر يضم القاعدة قبل شرحها (موجود)
3. الاكتشاف — Quiz 3 خيارات «ما القاعدة؟» (موجود، نحسّن بصرياً)
4. الشرح البصري — Rule card + جدول ملوّن + سهم تحول (موجود)
   ↳ جديد: Spatial Contiguity — الشرح بجانب المثال لا تحته
   ↳ جديد: Signaling — تلوين الحالات (Nominativ أزرق/Akkusativ أخضر/Dativ ذهبي/Genitiv بنفسجي)
5. التدريب المتدرّج — 3 تمارين + تغذية فورية (موجود)
   ↳ جديد: Layered Reveal — كل تمرين يكشف طبقة من الشرح
   ↳ جديد: Contrast — مقارنة الخطأ/الصواب جنباً إلى جنب
6. الفخاخ — جدار التحذير (موجود)
7. **جديد: التطبيق السياقي** — اكتب جملة حرة في سياق المشهد (Mayer Personalization)
8. **جديد: الخلاصة المرئية** — Concept Map / ورقة غش + شفرات + Anwendung حقل حر
```

#### ب) المبادئ الـ12 لماير (Multimedia Learning) — خريطة التطبيق

| مبدأ ماير | effect size | التطبيق في الدرس |
|---|---|---|
| Coherence | 0.70 | حذف كل زخرفة لا تخدم القاعدة — لا إيموجي عشوائي |
| Signaling | 0.46 | تلوين الحالات + أسهم التحول + highlight الفعل |
| Redundancy | 0.87 | لا نص + صوت متطابق في نفس اللحظة — الصوت عند الطلب (🔊) |
| Spatial Contiguity | 0.58 | القاعدة والمثال في نفس الكارت لا صفحتين |
| Temporal Contiguity | 0.31 | التغذية تظهر فور الاختيار لا بعد زر «صحح» |
| Segmenting | 0.56 | 5 خطوات ≤ نصف شاشة + تقدم شريط |
| Pre-training | 0.50 | المشهد قبل القاعدة — يعرف الهدف قبل المصطلح |

#### ج) التفاعلات الأربعة (Mayer + Conti + Goethe DLL)

1. **Prediction** — «ما القاعدة المشتركة؟» قبل الشرح (موجود — نحافظ)
2. **Contrast** — «✗ wegen dem Wetter → ✓ wegen des Wetters» جنباً إلى جنب (موجود — نحسّن إلى بطاقتين)
3. **Layered Reveal** — كل تمرين يكشف سطراً من الجدول (جديد — CSS max-height transition)
4. **Context Application** — «اكتب جملة في سياق المشهد» + تصحيح فوري بـ Feedback ثلاثي (جديد)

#### د) التغذية الثلاثية (3-part Feedback)

> كل إجابة → **ما الخطأ/الصواب + لماذا + الخطوة التالية**

```
✅ صحيح — weil يأتي بعد فاصلة ويقلب الفعل: «…weil ich müde bin.»
   → التالي: جرّب obwohl بنفس النمط.

✗ خطأ — «wegen» يأخذ Genitiv لا Akkusativ: «wegen des Wetters» ✓
   → راجع جدول Genitiv أعلاه ثم أعد المحاولة.
```

#### هـ) التفريق المستويات (CEFR + German Grammar Profile — 150 feature)

| المستوى | الهوية البصرية | العمق | الفخاخ | Authentic |
|---|---|---|---|---|
| A0-A1 | أيقونات كبيرة + جمل 3 كلمات + صوت في كل سطر | تأسيسي | بلا فخاخ | تحيات حقيقية |
| A2 | حوار شخصين + تلوين حالات | توسيع | فخ واحد | إعلان/رسالة |
| B1 | نص متكامل 120 كلمة + مهام كتابة | تحليل | 2 فخ | مقال مبسط |
| B2 | نص أكاديمي + تحولات Passiv/Nominalstil | تركيب | 4 فخاخ + تحذير امتحان | تقرير/مقال رأي |

المرجع: `content/grammar.json` — كل topic يحمل `level` + `voraus` + `rules` + `tables` — لا هجرة بيانات.
