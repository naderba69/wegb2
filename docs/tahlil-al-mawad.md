### ⛔ الثغرات الحرجة (يجب سدّها داخل المشروع)

1. **لا يوجد منهاج B2 إطلاقاً** (رغم اسم مجلد Menschen «A1, A2, B2» — المحتوى يتوقف عند B1.2).
2. **لا كتاب Kursbuch** لـ Menschen (النسخة المتاحة هي Arbeitsbuch + الحلول + الصوتيات).
3. **الكتابة (Schreiben) منعدمة** — لا تمارين إنتاج كتابي ولا نماذج إجابات مصححة.
4. **لا تمارين تفاعلية مصححة آلياً** — كل شيء PDF/صوت سلبي.
5. **لا خطة زمنية ولا تتبّع تقدّم ولا نظام تكرار متباعد**.
6. صيغ قديمة تحتاج تحويل: WMA (BBC) ، AVI (Planet/Muzzy) ، FLAC (Pimsleur IV).

### ✅ أصول المنصة (ما يبني عليها «المدرّس الافتراضي»)

1. **قاعدة متكاملة A1→B1** بمنهج واحد (Menschen) + تكاملات استماع (Hoeren Sie mal، Planet، Clips).
2. **15 امتحان محاكية B1 رسمياً** → وحدة «تكيّف امتحاني» كاملة.
3. **قواعد للعرب** (204 فعل شاذ، Grammatik für Araber، Noun Gender) → مادة شرح جاهزة.
4. **الألف جملة + Glossar** → بنك مفردات وجُمَل لبطاقات SRS.
5. نصوص مرافقة (Transkriptionen) للعديد من الوسائط → تدريبات Dictation/Shadowing.

## 4. الرؤية المعمارية للمشروع (Vercel · تكلفة 0)

### مبادئ
- **Offline-first · بدون قاعدة بيانات مدفوعة · بدون اشتراكات**.
- الملفات الثقيلة **تبقى على Drive** (روابط تشغيل مباشرة) — لا استضافة ولا تكاليف.
- كل المحتوى التعليمي المنظّم (دروس، شروحات، بنوك تمارين) يُكتب **JSON/MDX داخل الريبو**.
- التقدّم في `localStorage` + تصدير/استيراد JSON (نقل بين الأجهزة).

### الكومة التقنية
```
Next.js 15 (App Router) + TypeScript + Tailwind        → Vercel Free
محتوى: /content/*.json (دروس، تمارين، SRS decks)      → Static Build
وسائط: Google Drive direct/stream links               → خارج الاستضافة
التقدّم: localStorage + Export/Import                   → 0$
التكرار المتباعد: SM-2 مدمج (client-side)              → 0$
التصحيح الفوري: محرّك مطابقة/قواعد deterministic        → 0$
(اختيارياً لاحقاً): LLM API بمفتاح المستخدم            → غير مطلوب للـ MVP
```

### وحدات «المدرّس الوحيد» (المسار اليومي)
1. **محدّد المستوى** (Einstufungstest) → يضعك على المسار الصحيح.
2. **المسار A0→B2** مقسوم مستويات ← وحدات ← دروس (كل درس ≈ 45–60 دقيقة):
   إدخال قواعد (عربي) · مفردات SRS · استماع (من Drive + نص) · قراءة · تمرين مصحح · مهمة كتابة قصيرة.
3. **خطة اليوم** (Spaced Repetition + توزيع المهارات) — يغلق الدرس فقط عند تحقيق 80%+.
4. **مختبرات**: Hör-Labor (Shadowing/Dictation) · Grammatik-Labor (204 فعل + القواعد) · Sprech-Labor (تكرار/تسجيل بالنطق).
5. **امتحانات**: Placement + نصف-نهائي لكل مستوى + 15 نموذج B1 + Modellsatz B2.
6. **لوحة التقدّم**: CEFR can-do checklist · سلسلة الأيام · تنبؤ «متى تصل B2».

### حقوق النشر ⚖️
كتب Menschen/Pimsleur/Clips محفوظة بحقوق النشر. المنصة **لن تنشر أو تنسخ** هذه الملفات — تكتفي بـ**روابط Drive الخاصة بالمتعلّم نفسه** للاستخدام الشخصي. المحتوى المؤلَّف داخل المنصة (شروحات، تمارين، خرائط) من إنتاجنا.
