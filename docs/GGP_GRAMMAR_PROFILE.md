# مصفوفة تغطية القواعد وGGP — منهج الأدلة

**الحالة:** بنية داخلية قابلة للتدقيق، لا ادعاء GGP رسمي.
**مصدر الحقيقة الداخلي:** `content/grammar.json`.
**الحوكمة:** `content/grammar-profile-governance.json`.
**المصفوفة المولدة:** `content/grammar-profile-matrix.json`.

## 1. ما بُني فعلياً

حوّل المولد كل موضوع قواعد إلى سجل أدلة، وكل عبارة ثنائية اللغة داخل `rules` إلى **سمة مرشحة** مستقلة:

- 87 موضوعاً.
- 313 سمة مرشحة مشتقة من القواعد الحالية.
- 177 بند تحقق على مستوى الموضوع.
- 581 تمريناً على مستوى الموضوع.
- 285 مثالاً و200 فخ/خطأ شائع.
- 62 موضوعاً مرتبطة بمعرف Can-Do حالي، و25 لها هدف داخلي واضح لكنها تنتظر ربط Can-Do خارجي مناسب بدلاً من ربط فضفاض.

العدد 313 ناتج من المادة الموجودة، وليس محاولة لإغلاق رقم 150. لا يوجد في المستودع حتى الآن مصدر مرخص يثبت أن قائمة خارجية بعينها تحتوي 150 بنداً أو أن هذه البنود تطابقها.

## 2. حدود الدليل

وجود تمرين في موضوع لا يثبت تلقائياً أن كل قاعدة فرعية داخله مقاسة مباشرة. لذلك تسجل المصفوفة الأدلة الحالية بوصفها `topic-level-not-direct-feature-mapping`، وتبقي الربط المباشر بين سؤال وسمة `pending-item-level-map`.

كل سمة تحمل خمس حالات منفصلة:

1. الاشتقاق من المنهج الداخلي.
2. الربط بمصدر خارجي.
3. مراجعة وضعها في CEFR.
4. المراجعة اللغوية البشرية.
5. ربطها بقياس مباشر.

## 3. مسار المطابقة الأكاديمية

لا تتحول سمة إلى `verified` إلا بعد:

1. حفظ مصدر GGP أو ملف قواعد مستوى مرخص وقابل للاقتباس.
2. تسجيل الرابط والإصدار وتاريخ الاسترجاع وSHA-256 والترخيص.
3. تحديد الصفحة/المعرف الخارجي لكل سمة، لا الاكتفاء باسم كتاب.
4. توقيع مراجع لغوي مستقل على الوصف الألماني والعربي.
5. توقيع مراجع مستويات على A0/A1/A2/B1/B2.
6. ربط تمرين مباشر واحد على الأقل بالسمة، مع اختبار صحة المفتاح.
7. توثيق التبعيات بين السمات ومراجعة ترتيبها.

CEFR Companion Volume يمكنه تقديم سياق مستويات وقدرات، لكنه لا يُعامل تلقائياً كقائمة GGP نحوية.

## 4. الأوامر

```bash
# يعيد بناء المصفوفة حتمياً من grammar.json
npm run gen:ggp

# يثبت سلامة الاشتقاق ويعلن المراجعات المعلقة
npm run audit:ggp

# يبقى exit 2 حتى اكتمال المصدر والمراجعة والقياس المباشر لكل سمة
npm run audit:ggp:strict
```

تشغّل CI المولد ثم ترفض أي فرق غير ملتزم، وبعدها تشغل التدقيق العادي. الوضع الصارم لا يدخل CI قبل وصول الأدلة الخارجية، حتى لا تتحول المعلقات الحقيقية إلى فشل تقني يومي أو نجاح زائف.
