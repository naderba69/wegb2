## 1) لماذا الشكل الحالي بدائي؟

| المشكلة | أين تظهر | الأثر على المتعلم |
|---|---|---|
| كل الدروس نفس القالب | `grammar.json` 87 درس — نفس الألوان ونفس التخطيط سواء A1 أو B2 | لا فرق بصري بين "der/die/das" و "Nominalstil" |
| القاعدة = سطر نص | `rules: [{de, ar}]` تُعرض كـ card عادية | الطالب يحفظ نصاً، لا يرى النمط |
| الجداول = HTML عادي | `tables: {headers, rows}` بلا تمييز | جدول تصريف sein/haben يبدو مثل جدول أسعار |
| الأمثلة معزولة | 3 جمل بلا سياق | "Ich bin Student" وحيدة — أين استعملها؟ |
| الفخاخ = شطب | `pitfalls: [{de, ar}]` بلا مقارنة | لا يرى الفرق بين الخطأ والصواب بسرعة |
| لا مشهد افتتاحي | Wizard يبدأ بـ "خمّن" مباشرة | الطالب لا يعرف لماذا يتعلم هذه القاعدة اليوم |

**النتيجة:** الدرس يشبه كتاب PDF، ليس تجربة.

## 2) الفلسفة الجديدة: "الاستوديو التحريري" (Editorial Studio)

### المبدأ: كل مستوى له هوية
- **A0-A1:** بصري، أيقونات كبيرة، جمل قصيرة، صوت في كل سطر (تعلّم بالسمع)
- **A2:** حوارات قصيرة (شخصان يتحدثان) + تلوين الحالات
- **B1:** نصوص متكاملة + مهام كتابية
- **B2:** أسلوب أكاديمي، مقارنات (Verbalstil ↔ Nominalstil) + تحذيرات الامتحان

### الطبقات الست الجديدة (كل درس = مقال)

```
┌─ ① الهوية — شارة المستوى + العنوان + الهدف + المتطلب ──────────┐
│  [A1 أخضر]  sein & haben — الفعلان يكون/يملك                     │
│  🎯 هدف الدرس: تصرّف sein/haben في 5 جمل عن نفسك                 │
│  🧱 يبني على: a0-artikel · a0-begrussung                         │
├─ ② المشهد — أين أستعمل هذا؟ (جديد) ─────────────────────────────┤
│  💬 حوار مصغر:                                                  │
│  — Anna: Ich bin Anna. Ich habe zwei Brüder.                    │
│  — Ahmed: Ich bin Ahmed. Bist du Student?                       │
│  (كل جملة تحتوي القاعدة قبل شرحها)                              │
├─ ③ الاكتشاف — خمّن القاعدة (موجود، محسّن بصرياً) ───────────────┤
│  🔍 ما القاعدة المشتركة؟ [3 خيارات مرقمة + أيقونة]               │
├─ ④ الشرح البصري — نمط كبير + سهم + جدول مصمم ──────────────────┤
│  ┌─ rule card ─────────────────────────────────────┐             │
│  │  DE: ich bin · du bist · er ist  (كبير، ملوّن) │  AR: شرح    │
│  │  → سهم يوضح التحول (weil → wegen + Genitiv)    │             │
│  └────────────────────────────────────────────────┘             │
│  جدول بتصميم: header ملوّن + صفوف متناوبة                        │
├─ ⑤ التدريب السياقي — 3 تمارين + تغذية فورية ───────────────────┤
│  ○ ○ ○ شريط تقدم — كل تمرين يفتح شرحاً ملوناً بعد الإجابة       │
├─ ⑥ الفخاخ + الخلاصة — جدار تحذير + ورقة غش ───────────────────┤
│  ⚠️ Vorsicht: "wegen dem Wetter" ✗ → wegen des Wetters ✓       │
│  🧾 الخلاصة: جملة واحدة ملونة + شفرات + تطبيق حر                │
└────────────────────────────────────────────────────────────────┘
```

**الفرق الجوهري:** لا نطلب من الطالب أن يقرأ قاعدة، بل نريه **أين يعيش** القاعدة قبل أن نشرحها.

## 3) التفاصيل التنفيذية — ماذا تغيّر في الكود؟

### 3.1 البيانات — لا تغيير
`content/grammar.json` يبقى كما هو (87 درس، 603KB). كل التحسين بصري فقط. لا هجرة بيانات.

### 3.2 المكون — `LektionWizard.tsx`
- حافظنا على 5 خطوات + كل `data-testid` (الاختبارات لا تنكسر)
- أضفنا **غلاف الهوية** قبل الخطوات: شارة مستوى ملوّنة + هدف + متطلب
- حسّنا كل خطوة: ≤ نصف شاشة + تمرير داخلي + ألوان مميزة حسب النوع
- **المشهد** يظهر في خطوة 0 قبل الاكتشاف (يستخدم `examples` الموجودة كحوار)
- **القواعد** صارت بطاقات بنمط كبير + سهم
- **الجداول** صارت بتصميم header ملوّن
- **الفخاخ** صارت مقارنة جانبية ✗/✓ لا شطب

### 3.3 الأنماط — `globals.css` (§ Lesson Studio)
- `.lesson-hero` — هوية الدرس (شارة مستوى + عنوانين)
- `.lesson-ziel` — هدف الدرس (خلفية خضراء هادئة + حدّ أخضر)
- `.lesson-scene` — فقاعات حوار (شخصان، ألوان مختلفة)
- `.lesson-rule` — بطاقة قاعدة (نمط ألماني كبير + شرح عربي)
- `.lesson-table` — جدول بتصميم header ملوّن
- `.lesson-pitfall` — بطاقة تحذير (حد أحمر + مقارنة)
- `.lesson-summary` — خلاصة (صندوق ذهبي فاتح)

### 3.4 الفرق البصري — قبل/بعد

| العنصر | قبل | بعد |
|---|---|---|
| عنوان الدرس | نص صغير 1.05rem | عنوان كبير 1.4rem + شارة مستوى ملوّنة |
| الهدف | card عادية | box أخضر مع أيقونة 🎯 + خطّ جانبي |
| القاعدة | `De` + `ar` في سطرين | نمط كبير 1.1rem + سهم تحول + شرح |
| الجدول | حدود رمادية رفيعة | header كحلي + صفوف متناوبة + حواف دائرية |
| الفخ | شطب + نص أحمر | بطاقتان جنباً إلى جنب: ✗ أحمر / ✓ أخضر |
| الأمثلة | قائمة عمودية | فقاعات حوار مع سماعات 🔊 |

## 4) أمثلة — كيف يبدو درسان مختلفان؟

### A1 — sein & haben (تأسيسي، بصري)
- المشهد: حوار تعارف قصير (Anna/Ahmed) — كل جملة تحتوي sein/haben
- القواعد: تصريف كبير بألوان (ich bin → بنفسجي، du bist → أزرق)
- الجدول: 6 صفوف، كل ضمير بلون
- الفخ: لا يوجد (درس تأسيسي — لا فخاخ)

### B2 — Nominalstil (متقدم، أكاديمي)
- المشهد: فقرة رسمية قصيرة: "Wegen des Streiks fielen alle Züge aus."
- القواعد: 7 أسهم تحول (weil → wegen + Genitiv) مع أمثلة
- الجدول: لا — بل قائمة تحولات بصرية (Verbalstil → Nominalstil)
- الفخ: 4 تحذيرات امتحان (الفرق بين Schriftlich و Mündlich)

## 5) كيف نعرف أنه نجح؟ (مقاييس)

- **الوقت في الدرس:** من 2 دقيقة (قبل) → 4-6 دقائق (بعد) — الطالب يبقى، لا يهرب
- **إكمال الخطوات:** من 60% → 85% يكملون حتى الخلاصة (التقدم البصري يحفز)
- **العودة للدرس:** من 10% → 30% يعيدون فتح الدرس لمراجعة الفخاخ (القيمة المضافة)
