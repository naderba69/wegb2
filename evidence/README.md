# Evidence workspace

هذا المسار مخصص لآثار المراجعة التي يجوز حفظها في Git. سجل الحالات المركزي هو `content/external-evidence.json`، ولا تتغير حالته تلقائياً لمجرد وضع ملف هنا.

## قواعد

- لا تحفظ بيانات شخصية أو أصوات مشاركين أو مفاتيح أو مراسلات سرية.
- لا تنشر PDF/HTML محمياً إذا لم تسمح الرخصة؛ خزّن بصمته ومساره المقيد ومحضر الاستخراج فقط.
- استخدم UTC بصيغة ISO-8601 وSHA-256.
- افصل المنفذ عن المراجع عندما يتطلب الحاجز استقلالاً.
- التوقيع أثر مستقل، وليس اسماً مكتوباً داخل JSON فقط.
- لا تعدّل المصدر الخام؛ أنشئ محضر استخراج منفصلاً.

## تسمية مقترحة

`YYYY-MM-DD__record-id__artifact-type.ext`

مثال: `2026-11-05__G-B2-MODULES__source-review.pdf`

النماذج النصية في `evidence/templates/` تحدد الحد الأدنى، ويمكن تحويلها إلى PDF موقع خارج المستودع ثم تسجيل الأثر والبصمة.
